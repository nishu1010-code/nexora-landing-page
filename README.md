# Nexora Technologies - Landing Page

A modern landing page for **Nexora Technologies**, a (demo) web development agency. It presents the company, its services, technologies and a contact form in one scrollable page.

**Live Demo:** [nishu1010-code.github.io/nexora-landing-page](https://nishu1010-code.github.io/nexora-landing-page/)

> This is a practice project. Company name and contact details are for demonstration only.

<!-- Screenshot: add a screenshot to the repo, then use: ![Nexora Landing Page](screenshot.png) -->

## Sections

- **Navbar:** Home, About, Services, Technology, Contact and a "Get Started" button
- **Hero:** headline and call-to-action buttons
- **About:** short company introduction
- **Services:** Web Development, UI/UX Design, Performance, Responsive Design, Business Growth, Support
- **Technologies:** HTML5, CSS3, JavaScript, Git, GitHub, Responsive Design
- **Why Choose Us** and **Working Process** (Planning, Design, Development, Launch)
- **Contact:** form with name, email, subject and message
- **Footer:** quick links, social links and a scroll-to-top button

## Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts (Poppins)
- Font Awesome icons
